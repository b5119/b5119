# Contributing to my projects

Thanks for your interest! A few guidelines:

1. Fork the repo and create a branch: `git checkout -b feat/my-change`
2. Run tests locally and lint: `pytest` / `flake8`
3. Keep PRs small and descriptive.
4. Add tests for bug fixes/features.
5. Use conventional commits: `feat:`, `fix:`, `docs:`.

If you're new, look for issues labeled `good-first-issue`.
